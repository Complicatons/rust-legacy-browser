# Screenshot gallery — 19 October 2026

Actual captures from the private desktop browser prototype and its focused test scenes. These are rendered screenshots, not concept art. Development controls and unfinished graphics are shown as they currently appear. No original game assets or executable files are distributed in this gallery.

Online-labelled images use the project mock server. They do **not** demonstrate compatibility with a real Legacy server. Focused test scenes are labelled separately below.
