# Publication policy

The public repository documents the project without distributing the core implementation.

**Public:** curated progress updates, screenshots, roadmap, high-level hosting design, attribution and feedback discussions.

**Private:** implementation source, detailed protocol work, internal engineering notes, original or recovered game assets, client/server binaries, credentials, deployment secrets and player data.

Any future community SDK, bridge component or sample code must be reviewed and deliberately published with its own clear licence. No such software package is being released through this initial journal.

A public repository and its images can be copied or forked under GitHub's platform rules. Keeping source private limits access to implementation; it cannot make browser-delivered software impossible to inspect. Public documentation is not a technical copy-protection mechanism.

Before each publication, review the staged files and images for private information and confirm that every included file belongs in the public journal. Never copy the private repository's entire history into this repository.
