# Contributing

Thanks for taking an interest in the project. This repository currently accepts feedback and documentation improvements; the game implementation is private.

For feedback, open an issue with a specific suggestion or a clear description of the documented behaviour you are discussing. There is no public playable release yet, so please distinguish a suggestion from a reproducible report against an available build.

Do not upload game binaries, extracted assets, credentials, personal account data or material you do not have permission to share. Documentation pull requests should contain only your own contribution or appropriately attributed material you may submit.

Please credit Complicatons when discussing this browser-port project and preserve attribution to the original game's creators. Public source packages, if released later, will have their own contribution and licence terms.
